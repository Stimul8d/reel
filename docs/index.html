Getting it running

The important permission never asks, so the order matters.

  1. Unzip, drag Reel.app into Applications.
  2. First open is refused. System Settings > Privacy & Security, scroll down, Open Anyway.
  3. Same pane, Screen & System Audio Recording, turn Reel on. It is already listed, switched off.
  4. Quit and reopen. It only takes effect on the next launch.
Screen recording never prompts. There is no dialogue for it, ever. Skip step 3 and you get error -3801, which claims you declined something you were never asked.

Or build it. Command Line Tools, no Xcode, no package manager.

git clone https://github.com/Stimul8d/reel && cd reel
make signing-identity   # once per machine
make install            # -> ~/Applications/Reel.app
reel --probe            # what this Mac will allow

What it does not do yet

Forgets everything

The panel resets every launch. No login item.

Whole display only

No window picker, no region, no pause, no trim.

Never tidies up

Raw wavs are about 12 MB a minute and stay where they land.

Barely tested

Short recordings, one machine. Long ones and multiple displays, not yet.
